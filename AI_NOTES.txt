3. CODE GENERATED WITH AI VS. MANUAL MODIFICATIONS
--------------------------------------------------------------------------------
A. Generated via AI Assistance:
   - Initial draft schemas for Mongoose models (`DocumentChunk`, `TenderDocument`).
   - Regular expressions for GeM bilingual English/Hindi label extraction.
   - ExcelJS formatting presets (colors, cell borders, auto-fit columns).
   - Preliminary boilerplate for React drawers and score badges.

B. Critical Manual Modifications & Corrections:
   - Model ID Resolution: When `text-embedding-004` returned 404 in `@google/genai`
     v3, manually inspected available models via `ai.models.list()`, identified
     `gemini-embedding-001`, and configured `outputDimensionality: 768`.
   - Query Embedding Cache Key: Discovered that shared unit tests using mock providers
     polluted cache keys; updated cache key to include provider constructor name and
     model ID.
   - Windows Loopback Port Isolation: Discovered that starting Express inside Windows
     sandbox isolated port 5000 from host browser requests; executed with elevated host
     connectivity so Vite proxy (`http://127.0.0.1:5000`) succeeds.
   - Non-Tender Segregation: Prevented student assignments from appearing in the primary
     24-column Excel sheet; segregated non-tenders to the "Processing Summary" sheet.
   - Mongoose Connection Buffering: Added `dbStatus.isReady` guard checks before
     querying Mongoose models so offline unit tests do not hang on query buffering.

--------------------------------------------------------------------------------
4. SUGGESTIONS ACCEPTED VS. REJECTED
--------------------------------------------------------------------------------
Accepted Suggestions:
  - Preserving raw cosine similarity as a calibrated component rather than treating
    cosine similarity directly as a percentage.
  - Isolating deterministic keyword verdicts (`Related`, `Possible`, `Not Related`)
    from the AI-assisted 100-point hybrid score so baseline auditing is never corrupted.
  - Including Indian state names alongside industrial site names (e.g. "BANHARPALI, Odisha").
  - Adding suggested quick-question chips in the tender chat drawer for rapid review.

Rejected Suggestions:
  - Replacing the 24-column primary spreadsheet with a redesigned layout. REJECTED
    because maintaining 100% fidelity to `sample_tender_scan_report.xlsx` is mandatory.
  - Storing uploaded binary PDF files directly in MongoDB. REJECTED to avoid bloating
    Atlas collections; only extracted text, metadata, and embeddings are stored.
  - Relying on LLMs for exact monetary amounts or closing dates. REJECTED; dates and
    numbers are extracted deterministically via regex anchors to eliminate hallucination.
  - Adding heavyweight auth libraries (Passport/JWT). REJECTED as unnecessary complexity
    outside the assignment scope; replaced with lean in-memory rate limiting and CORS.
